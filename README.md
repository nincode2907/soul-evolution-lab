# Soul Evolution Lab

Trạm điều hành vòng tiến hóa của SoulCore: xem bằng chứng, đề xuất cải tiến, đo trước và sau, duyệt.

Trạng thái: mới khởi tạo, chưa có mã. Bản thiết kế sẽ nằm trong `docs/`.

Nguyên tắc:

- Tách hẳn khỏi SoulCore. Lab chỉ đọc dữ liệu của SoulCore; mọi thay đổi vào SoulCore phải qua nút duyệt của chủ sở hữu.
- Không lưu bí mật, token hay nội dung hội thoại trong repo này.
- Giao diện là trang web chạy cục bộ.
